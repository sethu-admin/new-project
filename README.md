# RedRoute

RedRoute is an experimental booking interface for buses and trains. The app uses React, TailwindCSS, Material UI, HeroUI and Three.js to deliver animated transitions, 3D seat selection and a reactive background inspired by Sony Xperia devices.

```
cd app
npm install
npm run dev
npm run build   # optional production build
npm run preview # preview production build
```

Navigate through the pages to search for routes, pick seats in 3D and complete passenger details. The background responds to cursor movement for an immersive feel.
The search form also supports optional voice input via the microphone buttons.

## UI Libraries

- **Material UI** provides form inputs and layout components
- **HeroUI** supplies accessible buttons and other interactive elements
